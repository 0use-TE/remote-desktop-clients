# 图片复制 · 0.1.16 本地测试版

连接电脑后，点击会话齿轮 → **复制图片到电脑** → 选择一张图片。
回到远程桌面后，在支持图片粘贴的 Windows 应用中按 **Ctrl+V**。
取消选图不会修改剪贴板。键盘菜单现在仅显示“键盘：Windows”或“键盘：安卓”；
Ctrl+Alt+F12 的切换行为保留。

使用 AndroidX 系统选图契约，只选择图片；较旧系统回退到文档选择器。
不申请读取整个相册的权限。选中的 URI、图片内容和文件名不会写入诊断日志。
解码、旋转处理和编码在专用后台线程运行，不在绘制或输入线程中执行。

图片通过现有 RDP CLIPRDR 通道提供 PNG、CF_DIBV5、CF_DIB 三种格式：

- PNG 和 DIBV5 提供透明度；24 位 DIB 为旧应用兼容格式，将透明区域合成到白底。
- 保留像素尺寸，输出 sRGB，不使用 JPEG 二次压缩。现代解码器和旧版 EXIF 路径均处理方向。
- 单张上限为 16,777,216 像素、任意边 8192 像素、PNG 数据 64 MiB。
  内存不足或图片过大时显示一次失败提示，不自动降低图片尺寸。
- 等 Windows 应用请求相应格式时发送实际图片；发出图片格式通知不代表目标应用已经粘贴。
- 新的安卓文字复制会恢复文字同步；原来的安卓文字不会覆盖刚选择的图片。
- 远端复制、替换图片或连接结束会清理旧图片；选图期间重连则要求重新选择，避免跨会话发送。

这是单张图片内容粘贴，不包含图片文件、视频或文件夹传输，也未加入反向图片同步。
GIF 等动态图片通过静态解码获得一帧。Windows 应用决定它接受的粘贴格式。

## 验证

主机测试检查 PNG 像素、DIBV5 通道/透明度/行方向、两条解码路径的 EXIF 旋转、
尺寸上限、取消处理、文字恢复及过期会话拒绝。
独立 Android 原生测试检查三个格式的通知与数据响应、24 位 DIB 行填充和白底合成、
不支持格式的失败响应、通知失败保留旧内容、远端接管、文字回退及回调恢复。
原生测试不安装或修改主应用。

实际选图和粘贴仍需安装后在 Windows 画图、聊天应用、Office 等目标应用中验收：
普通照片、带透明度 PNG、平板截图、旋转照片、取消选图、图片后复制文字、选图时断线。
本版只构建与传送 APK，由用户手动安装；不发布 GitHub Release。
